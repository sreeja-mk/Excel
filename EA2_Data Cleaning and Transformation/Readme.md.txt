#Excel Assignment 2 - Data Cleaning and Transformation

📌 Project Overview
        The main objective of this project is to improve data quality and prepare datasets for further analysis and visualization.

🎯 Objectives
       1. Handling Missing Values
       2. Correcting Inconsistent Data
       3. Removing Duplicates
       4. Splitting and Merging Data
       5. Number Formatting
       6. Conditional Formatting

🛠️ Tools and Technologies
         Excel

📈 Expected Outcomes
       1.Improved data quality and accuracy.
       2.Consistent and standardized datasets.
       3.Reduced data redundancy.
       4.Better data reliability.
       5.Analysis-ready datasets for visualization and reporting.

💡 Conclusion
       This project demonstrates the importance of data cleaning and transformation in the data analysis workflow. By identifying errors, handling missing values, removing duplicates, and standardizing data, raw datasets can be converted into meaningful and reliable information for further analysis.
